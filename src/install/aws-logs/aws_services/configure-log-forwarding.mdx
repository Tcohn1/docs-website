There are multiple ways to send New Relic logs from your AWS services, choose the path that best suits your needs and both the instegration instructions and the CloudFormation stack created will adjust based on your selections.

**First, select AWS sink(s)**

Most AWS services logs are generated into S3 buckets or CloudWatch Log Groups. Select one or both AWS sink(s)

**Next, select logs intgration path(s)**

Consider **Amazon Kinesis Data Firehose** integration for direct and high-volume data streaming and <DNT>**New Relic Lambda Function**</DNT> forwarder if high control over data transformation is needed before forwarding logs.

<img
  title="Select logs integration path "
  alt="screenshot showing the logs integration paths to select from."
  src=
/>

**Then, set up trigger(s)**

Setting up triggers ensures new logs are sent to New Relic everytime an AWS service log to a S3 bucket or CloudWatch Log Group. With a single cloudformation stack you can configure up to 40 triggers (S3 buckets and/or CloudWatch Log groups):

* For AWS service logs stored in S3 buckets, specify the **S3 bucket name** and **Prefix** (Optional)
* For AWS service logs stored in CloudWatch Log groups, specify the **Log Group name** and **Filter** (Optional)

<img

**Select New Relic logs API endpoint** [#choose-api-endpoint]

The system sets the endpoint by default based on the region of your New Relic account.
* For US account, logs are sent to `https://log-api.newrelic.com/log/v1`
* For EU account, logs are sent to `https://log-api.eu.newrelic.com/log/v1`
