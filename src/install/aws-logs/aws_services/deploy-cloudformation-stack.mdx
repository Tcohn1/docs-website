headingText: Deploy CloudFormation stack
componentType: default
---

Once your are done customizing the CloudFormation stack parameters so they meet your requirements, click the <DNT>**Create stack**</DNT> buttton.
It may take several minutes to create the new stack's resources. (Multiple stacks may be generated depending on how you configure log and metric forwarding).
With a single deployment command a new stack gets created to forward log from multiple AWS resources. 

If stack creation fails, refer the [troubleshooing procedures](/docs/logs/troubleshooting/aws-log-integration-issues/stack-creation-fails).
