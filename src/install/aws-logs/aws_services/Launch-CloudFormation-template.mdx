componentType: default
---

Click **Launch your CloudFormation in AWS** to navigate to your AWS Console. The CloudFormation stack will include the configured parameters based on your selections in New Relic One, so unless desired no additional editing is required.

**Note:** Make sure to copy and paste your license key in your AWS console. 
We reccommend to <DNT>**Store your New Relic License Key in AWS Secrets Manager**</DNT> by keeping the environment variable set to **true** (default value).
