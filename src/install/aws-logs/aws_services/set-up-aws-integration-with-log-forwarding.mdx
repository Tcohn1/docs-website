Using a single CloudFormation template you can easily set up your AWS integration and forward New Relic AWS services [metrics](/install/aws-cloudwatch/).
</Callout>, logs, or both.    
 
1. Log in to your [New Relic](https://one.newrelic.com/)account and navigate to [Integrations & Agents > AWS](https://one.newrelic.com/infra/marketplace/install-data-source)
2. Select a New Relic account and continue.
3. Select the telemetry type you wish to send to your New Relic account 
4. Select <DNT>**Automate AWS with CloudFoundation**</DNT> and continue. (Currently, this is the only setup method available for log integration).
